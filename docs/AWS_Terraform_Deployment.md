# AWS Infrastructure Deployment

## Overview

This project extends the local Apache Spark analytics pipeline by deploying the processed datasets and analytical environment to Amazon Web Services (AWS). Infrastructure was provisioned using Terraform, enabling reproducible deployment of cloud resources.

---

# Cloud Architecture

```
Local Spark Processing
        │
        ▼
Apache Spark (PySpark)
        │
Processed CSV Files
        │
        ▼
Amazon S3
        │
        ▼
AWS Glue Data Catalog
        │
        ▼
Amazon Athena
        │
        ▼
SQL Analytics & Validation
```

---

# Infrastructure Provisioning

Terraform was used to provision the AWS resources required for the cloud analytics pipeline.

The deployment created:

- Amazon S3 Bucket
- AWS Glue Database
- Amazon Athena Workgroup

Terraform enables infrastructure to be deployed consistently using Infrastructure as Code (IaC).

---

# Amazon S3

Bucket

```
ds-havi675-workspace
```

Purpose

- Store the IBM Credit Card Transactions dataset
- Store the ZIP Code (ZCTA) lookup dataset
- Store Athena query results

Directory Structure

```
data/
    transactions/
    zcta/
```

Amazon S3 acts as the primary cloud storage layer for the project.

---

# AWS Glue

Database

```
ds_havi675
```

Purpose

AWS Glue maintains the metadata describing datasets stored in Amazon S3.

Instead of copying data, Glue catalogs the schema and allows Amazon Athena to query the files directly.

---

# Amazon Athena

Workgroup

```
ds-havi675
```

Purpose

Amazon Athena performs serverless SQL analytics directly against datasets stored in Amazon S3.

Athena was used to validate the analytical results generated by Apache Spark.

Example analytical queries include:

- Fraud distribution
- Fraud by payment method
- Fraud by merchant category
- Fraud by state
- Fraud by ZIP Code

# Cloud Validation

After deployment, the infrastructure was validated by:

- Uploading datasets to Amazon S3
- Creating Glue metadata
- Executing SQL queries using Amazon Athena
- Comparing Athena query results with Apache Spark outputs

The cloud analytics produced results consistent with the local Spark analysis.

# Summary

The cloud component of this project demonstrates how Apache Spark analytics can be integrated with AWS services to create a scalable, reproducible, and serverless analytics pipeline.

Terraform simplified deployment by provisioning infrastructure automatically and ensuring consistent resource configuration.
